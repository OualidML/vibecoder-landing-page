# 🚀 Vibe Coder Playbook - Landing Page

Welcome to the repository for the **Vibe Coder Playbook** landing page. This project is a high-converting, cyberpunk-themed promotional website designed specifically to empower Algerian university students.

## 🎯 Project Overview
The **Vibe Coder Playbook** is a survival manual for students stuck on their graduation projects (PFE/Mémoires). It teaches **Vibe Coding**—the modern skill of building applications and resolving complex coding errors in seconds using Artificial Intelligence, without needing to memorize syntax.

### ✨ Key Highlights:
*   **Target Audience**: Algerian university students across all faculties (Tech, Medicine, Business, Law, etc.).
*   **The Core Offer**: A step-by-step AI programming and prompt engineering guide.
*   **Affiliate System (Abundance Mindset)**: A built-in collaborative model where students earn a **25% commission (500 DZD)** paid directly via **BaridiMob** for every successful referral.
*   **Omnichannel Strategy**: Optimized to convert traffic from Meta Ads (Instagram/Facebook), campus Délégué networks, and physical campus posters via tracked QR codes.

## 🛠️️ Tech Stack
*   **Frontend**: Pure HTML5 & Custom CSS3 (Featuring animated UI and responsive design)
*   **Deployment & Hosting**: [Netlify](https://www.netlify.com/)
*   **Analytics & Tracking**: Google Analytics 4 (GA4) & Meta Pixel (Configured for conversion tracking)
